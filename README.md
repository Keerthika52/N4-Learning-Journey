
# 🇯🇵 Japanese N4 Learning Journey

Welcome to my Japanese N4 Learning Repository!

I am learning Japanese to improve my language skills,
communicate confidently, and prepare for the JLPT N4
examination.

This repository documents my Japanese learning journey,
including vocabulary, grammar, kanji, reading, listening,
and regular practice tests.

- Achieve JLPT N4 proficiency
- Build a strong foundation in Japanese
- Improve everyday Japanese communication
- Develop Japanese reading and listening skills
- Prepare for future career opportunities in Japan
- Progress toward JLPT N3
